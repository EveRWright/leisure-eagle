# Leisure Eagle

Duck Hunt-style pixelated game.

**Concept:** You are an eagle flying down a valley/river. Scoop up as many octopuses as possible. Avoid condoms thrown by Leisure Suit Larry on the shore. Grab a condom = lose a life (eagle gets confused). Lives hit zero = game over.

Difficulty increases with levels (faster spawns, more condoms).

## Current status
- Playable canvas prototype on main: move with arrows/mouse, dive with space/click.
- Simple shapes for now (brown eagle, purple circles, white bars, white Larry).
- Score on octopuses, lives on condoms, level ramps.

## Sprites
Pixel art generated (Duck Hunt aesthetic):
- Flying eagle
- Purple octopus
- Larry in white suit on shore
- Floating condom

Assets can be added to /assets/ and loaded via Image() in next iteration.
