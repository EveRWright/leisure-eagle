# Leisure Eagle

Duck Hunt-style pixelated game.

**Concept:** You are an eagle flying down a valley/river. Scoop up as many octopuses as possible. Avoid condoms thrown by Leisure Suit Larry on the shore. Grab a condom = game over (eagle gets confused and dies).

Difficulty increases with levels/tracks.

## Sprites (generated)
- Eagle: pixel art flying eagle (Duck Hunt aesthetic)
- Octopus: purple pixel octopus in water
- Larry: white-suit guy on shore throwing objects
- Condom: floating white condom in water

Sprites generated during session. Add binary assets to /assets/ in future commits.
